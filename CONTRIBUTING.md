# Working on this project

Use Python 3.11 or later and a separate virtual environment for this repository.
Run the tests before submitting a change. Keep data preparation inside the
training pipeline where appropriate. Do not use test labels to select models,
checkpoints, thresholds, or features.

Record the changed configuration and rerun the experiment when you change a
method. Report measured results, including unsuccessful experiments. Cite
borrowed methods and preserve the dataset attribution. Do not commit local
environments, downloaded raw datasets, or exploratory outputs. The supplied
reference_run and labelled demo_run artifacts may remain in this educational
repository. Attach larger regenerated results to a release.
